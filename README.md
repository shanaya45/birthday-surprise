# Birthday Adventure - Final Version

This is the final birthday website build.

## Important
- The birthday gate is locked until **10 October 2026 at 12:00 AM IST**.
- The final build does not include a secret test unlock.
- The site uses the uploaded `a-thousand-years.mp3` for the music after the adventure opens. Browser autoplay policies can still require the music button to be tapped once.
- All 51 uploaded photos are included: 10 are used for Memory Lane and the remaining 41 are used in the scrapbook.
- The final Happy Birthday page uses a replacement favourite photo (`images/favorite-photo.jpg`).
- Memory Lane answers are submitted through FormSubmit to the email address configured in the form. The first real submission may trigger a one-time destination-email confirmation.
- The Diet Coke chapter uses the custom cinematic Diet Coke universe artwork at `images/diet-coke-universe.png`. The can remains interactive through a transparent responsive tap target over the can.

## GitHub Pages
Upload the contents of this folder to your GitHub repository, with `index.html` at the repository root, then enable GitHub Pages from the repository's Pages settings.

## Testing before the birthday
For a private local test, temporarily change the countdown condition in `script.js` so the adventure opens immediately, then restore the original date-lock condition before publishing. Do not publish the test change.
